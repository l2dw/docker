# authentik

[Authentik](https://goauthentik.io) identity (`ghcr.io/goauthentik/server`). **External Postgres** (`AUTHENTIK_POSTGRESQL__*`); no database or Redis in this stack (Redis dropped in 2025.10). Joins `dokploy-network`. Traefik/Homepage labels live only in `docker-compose.yml` on **authentik-server** (HTTP **9000**, not published). Worker has no ingress. Docker socket is **not** mounted (deploy outposts yourself).

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${AUTHENTIK_SERVER_ENV_FILE:-.env.example}` / `${AUTHENTIK_WORKER_ENV_FILE:-.env.example}`; production: `*.ENV_FILE=.env`. `environment:` wins on key conflicts.

Do **not** set `TZ` on authentik containers (vendor: OAuth/SAML clock issues).

Create the Postgres database and role first (e.g. on `dokploy-postgresql`), then:

```sh
make authentik-setup \
  AUTHENTIK_DOMAIN=authentik.example.com \
  AUTHENTIK_POSTGRESQL__HOST=dokploy-postgresql \
  AUTHENTIK_POSTGRESQL__USER=authentik \
  AUTHENTIK_POSTGRESQL__NAME=authentik \
  AUTHENTIK_POSTGRESQL__PASSWORD=secret
make authentik-stack-up
# or
make authentik-compose-up
```

Initial setup UI: `http://<AUTHENTIK_DOMAIN>/authentik/if/flow/initial-setup/` (path follows `AUTHENTIK_WEB__PATH`). `authentik-setup` generates `AUTHENTIK_SECRET_KEY` when empty or `ChangeMe`.

On the `authentik` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `authentik/`.

## Base path

**Supported** via vendor `AUTHENTIK_WEB__PATH` (leading **and** trailing slash, e.g. `/authentik/`). Default `AUTHENTIK_BASE_PATH=/authentik` for Traefik `PathPrefix` (no `stripPrefix` — authentik serves the prefix). `AUTHENTIK_WEB__BASE_URL` is scheme+host only (`http://authentik.example.com`). Dedicated subdomain: `AUTHENTIK_BASE_PATH=/`, `AUTHENTIK_WEB__PATH=/`, and update `homepage.href` / `siteMonitor`.

## Required env

| Variable | Notes |
|----------|--------|
| `AUTHENTIK_DOMAIN` | Traefik Host() (warns if `example.com`) |
| `AUTHENTIK_POSTGRESQL__HOST` / `__USER` / `__NAME` / `__PASSWORD` | External DB (warns if `ChangeMe`) |
| `AUTHENTIK_SECRET_KEY` | Generated by `authentik-setup` |
| `AUTHENTIK_SERVER_ENV_FILE` / `AUTHENTIK_WORKER_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `APP_NAME` | Optional. Dokploy sets this; **not** in `.env.example`. Traefik names default to `authentik`. |

Do not commit `authentik/.env` or real secrets.
