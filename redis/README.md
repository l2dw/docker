# redis

Official [Redis](https://hub.docker.com/_/redis) (`docker.io/library/redis:7-alpine`) on **TCP 6379**. Joins `dokploy-network`. **Not an HTTP app**: no Traefik/Homepage labels (`compose.yml` is a symlink of `docker-compose.yml`).

Port **6379 is not published on the host**. Other stacks on the overlay reach Redis as **`dokploy-redis:6379`** (network alias, Dokploy-style) or `redis:6379` (Compose service name).

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${REDIS_ENV_FILE:-.env.example}`; production: `REDIS_ENV_FILE=.env`. `environment:` wins on key conflicts.

```sh
make redis-setup
make redis-stack-up
# or
make redis-compose-up
```

On the `redis` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `redis/`.

## Base path

**Not applicable.** Redis is TCP, not HTTP. `REDIS_BASE_PATH=/` is unused. Do not put Traefik `PathPrefix` or `stripPrefix` on this service.

## Auth and persistence

`make redis-setup` writes `REDIS_PASSWORD` (openssl hex) into `redis/.env` and the root `.env` if empty. The official image **ignores** `REDIS_PASSWORD` / `REDIS_ARGS` as server config; Compose interpolates the password onto:

`redis-server --appendonly yes --requirepass <REDIS_PASSWORD>`

AOF data lives in `/data` (`REDIS_DATA_DIR`). Clients on the overlay (prefer the alias expected by app stacks):

```
redis://:${REDIS_PASSWORD}@dokploy-redis:6379/0
```

Override the alias with `REDIS_NETWORK_ALIAS` (default `dokploy-redis`). After changing it, redeploy the stack.

## Required env

| Variable | Notes |
|----------|--------|
| `REDIS_PASSWORD` | Generated by `make redis-setup` if empty |
| `REDIS_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `REDIS_IMAGE` | Default `docker.io/library/redis:7-alpine` |
| `REDIS_NETWORK_ALIAS` | Overlay DNS alias (default `dokploy-redis`) |

Do not commit `redis/.env` or real passwords.
