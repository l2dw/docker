# redis

Official [Redis](https://hub.docker.com/_/redis) (`docker.io/library/redis:7-alpine`) on **TCP 6379**. **Not an HTTP app**: no Traefik/Homepage labels (`compose.yml` is a symlink of `docker-compose.yml`).

Port **6379 is not published on the host**. Other stacks on the overlay reach Redis as **`dokploy-redis:6379`** (alias) or `redis:6379` (Compose service name).

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${REDIS_ENV_FILE:-.env.example}`; production: `REDIS_ENV_FILE=.env`. `environment:` overrides the file.

```sh
make redis-setup
make redis-stack-up
# or
make redis-compose-up
```

## Base path

**Not applicable.** Redis is TCP. `REDIS_BASE_PATH=/` is unused.

## Auth and persistence

`make redis-setup` generates `REDIS_PASSWORD` if empty and syncs `DEFAULT_NETWORK_EXTERNAL`. The official image ignores `REDIS_PASSWORD` as server config; Compose interpolates:

`redis-server --appendonly yes --requirepass <REDIS_PASSWORD>`

AOF data: volume key `data` → `/data`. Client URL:

```
redis://:${REDIS_PASSWORD}@dokploy-redis:6379/0
```

Override alias with `REDIS_NETWORK_ALIAS` (default `dokploy-redis`). Also aliases `${APP_NAME:-redis}`.

## Networks

| Goal | `DEFAULT_NETWORK_NAME` | `EXTERNAL` |
|------|------------------------|------------|
| Stack-local (default) | `redis-network` | `false` |
| Shared Dokploy / apps | `dokploy-network` | `true` |

`make redis-setup` upserts `DEFAULT_NETWORK_EXTERNAL` (`true` **only** for `dokploy-network`) and creates the network when external is false.

```sh
docker network create redis-network --driver overlay   # Swarm
docker network create redis-network --driver bridge    # Compose
```

## Volumes

Compose key **`data`** → `${REDIS_DATA_VOLUME_DIR:-/data}`:

| Mode | `EXTERNAL` | `TYPE` | `OPTS` | `PATH` |
|------|------------|--------|--------|--------|
| Local named (default) | `false` | empty | empty | empty |
| Bind | `false` | `none` | `bind` | `/appdata/redis` |
| NFS | `false` | `nfs` | `addr=host,rw,nfsvers=4` | `:/exports/redis` |
| External | `true` | — | — | — |

```env
# Local named
REDIS_DATA_VOLUME_TYPE=
REDIS_DATA_VOLUME_OPTS=
REDIS_DATA_VOLUME_PATH=
REDIS_DATA_VOLUME_DIR=/data

# Bind
REDIS_DATA_VOLUME_TYPE=none
REDIS_DATA_VOLUME_OPTS=bind
REDIS_DATA_VOLUME_PATH=/appdata/redis
```

```sh
docker volume create redis_data
```

## Required env

| Variable | Notes |
|----------|--------|
| `REDIS_PASSWORD` | Generated by `make redis-setup` if empty |
| `REDIS_ENV_FILE` | Default `.env.example` |
| `REDIS_IMAGE` | Default `docker.io/library/redis:7-alpine` |
| `REDIS_NETWORK_ALIAS` | Default `dokploy-redis` |
| `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL` | Default `redis-network` / `false` |

Do not commit `redis/.env` or real passwords.
