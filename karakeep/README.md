# karakeep

[Karakeep](https://karakeep.app) (formerly **Hoarder**) — self-hosted bookmarks and notes. Official images: `ghcr.io/karakeep-app/karakeep` and Chrome helper. Joins `dokploy-network`. Traefik/Homepage labels live only in `docker-compose.yml` on **`karakeep-web`**.

HTTP **3000 is not published on the host** — Traefik routes `Host(KARAKEEP_DOMAIN)`. Chrome (9222) stays on the overlay. Meilisearch is **not** deployed here: set `KARAKEEP_MEILI_ADDR` (and `KARAKEEP_MEILI_MASTER_KEY`) to an existing instance, e.g. `http://meilisearch:7700`. Empty `MEILI_ADDR` disables search.

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${KARAKEEP_WEB_ENV_FILE:-.env.example}` (and `KARAKEEP_CHROME_ENV_FILE`); production: `KARAKEEP_*_ENV_FILE=.env`. `environment:` wins on key conflicts.

```sh
make karakeep-setup \
  KARAKEEP_DOMAIN=karakeep.example.com \
  KARAKEEP_APP_URL=http://karakeep.example.com \
  KARAKEEP_NEXTAUTH_URL=http://karakeep.example.com
make karakeep-stack-up
# or
make karakeep-compose-up
```

On the `karakeep` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `karakeep/`.

## Base path

**Not supported.** Next.js / NextAuth expect the app at the origin root. Default `KARAKEEP_BASE_PATH=/` is unused. Traefik is **Host-only** (`KARAKEEP_DOMAIN`). Do not use `PathPrefix` or `stripPrefix`. Set `KARAKEEP_NEXTAUTH_URL` to the public origin (same as `KARAKEEP_APP_URL`). OAuth callback: `<NEXTAUTH_URL>/api/auth/callback/custom`. See [Docker install](https://docs.karakeep.app/installation/docker) and [configuration](https://docs.karakeep.app/configuration).

## Credentials and volumes

`make karakeep-setup` generates `KARAKEEP_NEXTAUTH_SECRET` if empty. Warns if `KARAKEEP_OPENAI_API_KEY` or `KARAKEEP_MEILI_ADDR` is empty (tagging / search off).

Named volume: `/data` on web (SQLite + assets). Leave `DATA_DIR=/data` inside the container.

## Required env

| Variable | Notes |
|----------|--------|
| `KARAKEEP_DOMAIN` | Traefik Host() (warns if `example.com`) |
| `KARAKEEP_APP_URL` / `KARAKEEP_NEXTAUTH_URL` | Public origin (Homepage + NextAuth) |
| `KARAKEEP_NEXTAUTH_SECRET` | Generated by setup if empty |
| `KARAKEEP_WEB_ENV_FILE` / `KARAKEEP_CHROME_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `KARAKEEP_MEILI_ADDR` / `KARAKEEP_MEILI_MASTER_KEY` | External Meili (empty addr = no search) |

Optional: `KARAKEEP_OPENAI_API_KEY` for tagging. Do not commit `karakeep/.env` or real secrets.
