# mysql

Official [MySQL](https://hub.docker.com/_/mysql) (`docker.io/library/mysql:8.0`) on **TCP 3306**. Uses the stack-local `mysql-network` by default (`external=false`). **Not an HTTP app**: no Traefik/Homepage labels (`compose.yml` is a symlink of `docker-compose.yml`).

On the overlay, reach MySQL as **`mysql-server:3306`** (network alias) or `server:3306` (Compose service name). Host publish defaults to **`23306→3306`** (`MYSQL_PUBLISHED_PORT` / `MYSQL_PORT`, Swarm `ingress`, protocol `tcp`). Prefer overlay access; for intentional inter-stack access, use a shared external network.

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${MYSQL_ENV_FILE:-.env.example}`; production: `MYSQL_ENV_FILE=.env`. `environment:` wins on key conflicts.

```sh
make mysql-setup
make mysql-stack-up
# or
make mysql-compose-up
```

On the `mysql` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `mysql/`.

## Base path

**Not applicable.** MySQL is TCP, not HTTP. `MYSQL_BASE_PATH=/` is unused.

## Auth and persistence

`make mysql-setup` generates `MYSQL_ROOT_PASSWORD` and `MYSQL_PASSWORD` (openssl hex) when empty, and keeps `DEFAULT_NETWORK_EXTERNAL=false` for the default stack-local `mysql-network`.

Default database/user: `MYSQL_DATABASE=mysql`, `MYSQL_USER=mysql`. Data is mounted at `/var/lib/mysql` from `MYSQL_DATA_HOST_PATH` (default `data`), with configurable volume driver options.

Clients on the overlay:

```
mysql://${MYSQL_USER}:***@mysql-server:3306/${MYSQL_DATABASE}
```

Root:

```
mysql://root:${MYSQL_ROOT_PASSWORD}@mysql-server:3306/
```

Healthcheck uses `mysqladmin ping` against `127.0.0.1` with the root password from the container env. Override the alias with `MYSQL_NETWORK_ALIAS` (default `mysql-server`). Swarm updates use `stop-first` (single replica + datadir).

## Required env

| Variable | Notes |
|----------|--------|
| `MYSQL_ROOT_PASSWORD` | Generated by `make mysql-setup` if empty |
| `MYSQL_PASSWORD` | Generated by `make mysql-setup` if empty |
| `MYSQL_DATABASE` / `MYSQL_USER` | Default `mysql` / `mysql` |
| `MYSQL_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `MYSQL_NETWORK_ALIAS` | Stack-local DNS alias (default `mysql-server`) |
| `MYSQL_PUBLISHED_PORT` / `MYSQL_PORT` | Host→container publish (default `23306`→`3306`) |
| `MYSQL_PORT_MODE` | Swarm publish mode (`ingress`\|`host`; protocol is `tcp` in compose) |
| `MYSQL_HEALTHCHECK_*` | Interval/timeout/retries/start_period for `mysqladmin ping` |
| `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL` | Default stack-local `mysql-network` with `external=false`; set both explicitly for shared external access |
| `MYSQL_DATA_HOST_PATH` / `MYSQL_DATA_CONTAINER_PATH` | Volume source (`mysql-data`) and container mount (`/var/lib/mysql`) |
| `MYSQL_DATA_VOLUME_DRIVER*` | Optional Docker volume driver and `driver_opts` overrides |

Do not commit `mysql/.env` or real passwords.
