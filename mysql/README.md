# mysql

Official [MySQL](https://hub.docker.com/_/mysql) (`docker.io/library/mysql:8.0`) on **TCP 3306**. Uses the stack-local `mysql-network` by default. **Not an HTTP app**: no Traefik/Homepage labels (`compose.yml` is a symlink of `docker-compose.yml`).

Port **3306 is not published on the host**. Other stacks on the overlay reach MySQL as **`mysql-server:3306`** or `mysql:3306` (Compose service name).

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${MYSQL_ENV_FILE:-.env.example}`; production: `MYSQL_ENV_FILE=.env`. `environment:` wins on key conflicts.

```sh
make mysql-setup
make mysql-stack-up
# or
make mysql-compose-up
```

On the `mysql` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `mysql/`.

## Base path

**Not applicable.** MySQL is TCP, not HTTP. `MYSQL_BASE_PATH=/` is unused.

## Auth and persistence

`make mysql-setup` generates `MYSQL_ROOT_PASSWORD` and `MYSQL_PASSWORD` (openssl hex) when empty, and keeps `DEFAULT_NETWORK_EXTERNAL=false` for the default stack-local `mysql-network`.

Default database/user: `MYSQL_DATABASE=mysql`, `MYSQL_USER=mysql`. Data in `/var/lib/mysql` (`MYSQL_DATA_DIR` named volume by default).

Clients on the overlay:

```
mysql://${MYSQL_USER}:${MYSQL_PASSWORD}@mysql-server:3306/${MYSQL_DATABASE}
```

Root:

```
mysql://root:${MYSQL_ROOT_PASSWORD}@mysql-server:3306/
```

Override the alias with `MYSQL_NETWORK_ALIAS` (default `mysql-server`). Swarm updates use `stop-first` (single replica + datadir).

## Required env

| Variable | Notes |
|----------|--------|
| `MYSQL_ROOT_PASSWORD` | Generated by `make mysql-setup` if empty |
| `MYSQL_PASSWORD` | Generated by `make mysql-setup` if empty |
| `MYSQL_DATABASE` / `MYSQL_USER` | Default `mysql` / `mysql` |
| `MYSQL_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `MYSQL_NETWORK_ALIAS` | Overlay DNS alias (default `mysql-server`) |
| `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL` | Default stack-local network `mysql-network` with `external=false` |
| `MYSQL_DATA_DIR` | Named volume source (`mysql-data` by default) |
| `MYSQL_DATA_VOLUME_DRIVER*` | Optional Docker volume driver and `driver_opts` overrides |

Do not commit `mysql/.env` or real passwords.
