# Nextcloud

[Nextcloud](https://hub.docker.com/_/nextcloud) 27 (`docker.io/library/nextcloud:27`). Database **type** is PostgreSQL (≤ 15) on an **external** host — this stack does not run Postgres.

Default overlay is **`nextcloud-network`** (`DEFAULT_NETWORK_EXTERNAL=false`). To reach Traefik or an external DB on a shared overlay, set `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL=true` and point `NEXTCLOUD_DB_HOST` at that Postgres DNS name.

Docs: [official image](https://hub.docker.com/_/nextcloud), [system requirements](https://docs.nextcloud.com/server/27/admin_manual/installation/system_requirements.html).

`.env` is **not** read by `docker stack deploy` alone — use Make (root `.env` is exported). Compose `env_file` loads `${NEXTCLOUD_ENV_FILE:-.env.example}`; `environment:` wins on conflicts. Production: `NEXTCLOUD_ENV_FILE=.env`.

```sh
make nextcloud-setup \
  NEXTCLOUD_DOMAIN=nextcloud.example.com \
  NEXTCLOUD_APP_URL=https://nextcloud.example.com/nextcloud
make nextcloud-stack-up
# or
make nextcloud-compose-up
```

On the `nextcloud` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `nextcloud/`.

| File | Labels |
|------|--------|
| [`compose.yml`](compose.yml) | None (no Traefik / Homepage) |
| [`docker-compose.yml`](docker-compose.yml) | Traefik + Homepage — used by `make` |

## Base path

Supported via vendor **`OVERWRITEWEBROOT`**. Apache in the image still serves at `/`, so Traefik **`stripPrefix`** (`nextcloud-strip`) is attached by default.

- Default: `NEXTCLOUD_BASE_PATH=/nextcloud`, `OVERWRITEWEBROOT=/nextcloud`, `NEXTCLOUD_APP_URL=http://nextcloud.example.com/nextcloud`, `NEXTCLOUD_MIDDLEWARES=nextcloud-strip`
- Root on a dedicated subdomain: `NEXTCLOUD_BASE_PATH=/`, `NEXTCLOUD_OVERWRITEWEBROOT=` (empty), `NEXTCLOUD_MIDDLEWARES=` (empty), `NEXTCLOUD_APP_URL=https://cloud.example.com`

Keep `OVERWRITEHOST` / `NEXTCLOUD_TRUSTED_DOMAINS` aligned with `NEXTCLOUD_DOMAIN`. Set `OVERWRITEPROTOCOL=https` when TLS is on.

## Makefile

```sh
make nextcloud-setup
make nextcloud-pull-images
make nextcloud-stack-up
make nextcloud-stack-upgrade
make nextcloud-stack-down
make nextcloud-stack-logs
make nextcloud-debug
make nextcloud-debug-logs
make nextcloud-compose-up
make nextcloud-compose-down
make nextcloud-compose-restart
```

Setup generates admin/DB passwords when empty, warns on `example.com`, and syncs `DEFAULT_NETWORK_EXTERNAL` (`false` for `nextcloud-network`; `true` only when NAME is an opted-in shared overlay such as `dokploy-network`).

## Required env

| Variable | Notes |
|----------|--------|
| `NEXTCLOUD_ADMIN_PASSWORD` | Generated by `nextcloud-setup` if empty |
| `NEXTCLOUD_DB_HOST` | External Postgres (default `postgresql`) |
| `NEXTCLOUD_DB_NAME` / `NEXTCLOUD_DB_USER` | Default `nextcloud` |
| `NEXTCLOUD_DB_PASSWORD` | Generated by setup; must match the external DB |
| `NEXTCLOUD_APP_URL` | Public URL including base path |
| `NEXTCLOUD_DOMAIN` | Traefik `Host()` + `OVERWRITEHOST` |
| `NEXTCLOUD_BASE_PATH` | Traefik `PathPrefix` (default `/nextcloud`) |
| `NEXTCLOUD_MEMORY_LIMIT` | Default `1G` |
| `NEXTCLOUD_ENV_FILE` | Compose dotenv (default `.env.example`; use `.env` in production) |
| `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL` | Default `nextcloud-network` / `false` |

Create the database and role on the external Postgres **before** first boot. Auto-install runs when admin + postgres vars are set. HTTP **80** is not published; Traefik routes it.

## Volumes

| Mount | Var | Default |
|-------|-----|---------|
| `/var/www/html` | `NEXTCLOUD_HTML_DIR` | `nextcloud-html` |
| `/var/www/html/data` | `NEXTCLOUD_DATA_DIR` | `nextcloud-data` |

Swarm treats `${NEXTCLOUD_*_DIR}:…` as **named volumes** after interpolation — do not put `/appdata/...` in those vars.

## Traefik `APP_NAME`

Dokploy often injects `APP_NAME`. Traefik **router/service** names (and the strip middleware) use `${APP_NAME:-nextcloud}` so multiple Nextcloud apps on the same Traefik do not collide. The Compose service key stays `nextcloud` (overlay DNS / `homepage.siteMonitor`). Do **not** put `APP_NAME` in `.env.example`. `make nextcloud-setup` sets `NEXTCLOUD_MIDDLEWARES` to `<APP_NAME>-strip` (or clears it when `BASE_PATH=/`).

Swarm/Compose **`configs:`** mounts [`config/zzz-custom.config.php`](config/zzz-custom.config.php) at `/var/www/html/config/zzz-custom.config.php` (`mode: 0444`). Path: `NEXTCLOUD_CUSTOM_CONFIG`. Do **not** replace `config.php`. Extra `*.config.php` files are merged ([sample parameters](https://docs.nextcloud.com/server/27/admin_manual/configuration_server/config_sample_php_parameters.html)). The `zzz-` prefix loads last. After editing the file, recreate the stack so Swarm picks up a new config version.
