# NocoDB

[NocoDB](https://nocodb.com/docs/self-hosting/) Airtable-style spreadsheet over your data — image `nocodb/nocodb:2026.08.1` (HTTP **8080**). Default database is **SQLite** under `/usr/app/data/` when `NOCODB_DB` is empty.

Default overlay is **`nocodb-network`** (`DEFAULT_NETWORK_EXTERNAL=false`). To reach Traefik (or external Postgres) on a shared overlay, set `DEFAULT_NETWORK_NAME=dokploy-network` and `DEFAULT_NETWORK_EXTERNAL=true`.

Docs: [environment variables](https://nocodb.com/docs/self-hosting/environment-variables), [Docker Hub](https://hub.docker.com/r/nocodb/nocodb).

`.env` is **not** read by `docker stack deploy` alone — use Make (root `.env` is exported). Compose `env_file` loads `${NOCODB_ENV_FILE:-.env.example}`; `environment:` wins on conflicts. Production: `NOCODB_ENV_FILE=.env`.

```sh
make nocodb-setup \
  NOCODB_DOMAIN=nocodb.example.com \
  NOCODB_APP_URL=https://nocodb.example.com \
  NOCODB_SITE_URL=https://nocodb.example.com
make nocodb-stack-up
# or
make nocodb-compose-up
```

External Postgres (optional — this stack does not run Postgres):

```sh
# NOCODB_DB=pg://postgresql:5432?u=nocodb&p=ChangeMe&d=nocodb
```

On the `nocodb` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `nocodb/`.

| File | Labels |
|------|--------|
| [`compose.yml`](compose.yml) | None (no Traefik / Homepage) |
| [`docker-compose.yml`](docker-compose.yml) | Traefik + Homepage — used by `make` |

`APP_NAME` (Dokploy) scopes Traefik router/service names; it is **not** listed in `.env.example`. Compose DNS stays `nocodb` (`homepage.siteMonitor`).

## Base path

**Not supported** for reliable subpath deploy (SPA / asset issues). Keep `NOCODB_BASE_PATH=/` on a dedicated subdomain (Host-only). Do not rely on Traefik `stripPrefix`. `nocodb-setup` warns if `BASE_PATH` is not `/`.

## Makefile

```sh
make nocodb-setup
make nocodb-pull-images
make nocodb-stack-up
make nocodb-stack-upgrade
make nocodb-stack-down
make nocodb-stack-logs
make nocodb-debug
make nocodb-debug-logs
make nocodb-compose-up
make nocodb-compose-down
make nocodb-compose-restart
```

Setup generates `NOCODB_AUTH_JWT_SECRET` when empty, aligns `NOCODB_SITE_URL` with `APP_URL` when needed, warns on `example.com`, and syncs `DEFAULT_NETWORK_EXTERNAL` (`true` only for `dokploy-network`).

## Required env

| Variable | Notes |
|----------|--------|
| `NOCODB_AUTH_JWT_SECRET` | Generated by `nocodb-setup` if empty |
| `NOCODB_DOMAIN` | Traefik `Host()` |
| `NOCODB_APP_URL` / `NOCODB_SITE_URL` | Public URL (vendor `NC_SITE_URL`) |
| `NOCODB_BASE_PATH` | Must stay `/` |
| `NOCODB_DB` | Omit for SQLite; for Postgres see README (add `NC_DB` to compose) |
| `NOCODB_MEMORY_LIMIT` | Default `1G` |
| `NOCODB_ENV_FILE` | Compose dotenv (default `.env.example`; use `.env` in production) |
| `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL` | Default `nocodb-network` / `false` |

First boot creates the admin account in the UI. HTTP **8080** is not published; Traefik routes it.
