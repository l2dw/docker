# SiYuan

[SiYuan](https://github.com/siyuan-note/siyuan) — local-first knowledge base (`b3log/siyuan`, HTTP **6806**). Traefik on `docker-compose.yml`; unlabeled `compose.yml`.

## Quick start

```sh
make siyuan-setup
# Edit siyuan/.env — SIYUAN_DOMAIN / SIYUAN_APP_URL / auth code
make siyuan-stack-up      # Swarm
# or
make siyuan-compose-up    # Compose
```

Debug: `make siyuan-debug` / `make siyuan-debug-logs`.

`docker stack deploy` does **not** load Compose `env_file` reliably — use Make (exports root `.env`) + `environment:` interpolation.

## Base path

Subpath is **not** supported. Keep `SIYUAN_BASE_PATH=/` and a dedicated subdomain (`SIYUAN_DOMAIN`). Reverse proxy must forward WebSocket `/ws` (`passhostheader=true`).

## Traefik / Homepage

Labels: Traefik only in `docker-compose.yml`. Homepage on both compose files. `APP_NAME` scopes Traefik router/service names.

## Credentials

`SIYUAN_ACCESS_AUTH_CODE` — generated by `make siyuan-setup` when empty/`ChangeMe`.

## env_file

`SIYUAN_ENV_FILE` (default `.env.example`). Production → `.env`. `environment:` overrides. Swarm: Make-exported root `.env`.

## Networks

| Goal | `DEFAULT_NETWORK_NAME` | `EXTERNAL` |
|------|------------------------|------------|
| Stack-local (default) | `siyuan-network` | `false` |
| Shared Traefik / apps | `dokploy-network` | `true` |

`make siyuan-setup` upserts `DEFAULT_NETWORK_EXTERNAL` (`true` only for `dokploy-network`) and creates the network when external is false.

```sh
docker network create siyuan-network --driver overlay   # Swarm
docker network create siyuan-network --driver bridge    # Compose
```

## Volumes

| Compose key | Container path | Default name |
|-------------|----------------|--------------|
| `data` | `/siyuan/workspace` | `siyuan_workspace` |

| Mode | `EXTERNAL` | `TYPE` | `OPTS` | `PATH` |
|------|------------|--------|--------|--------|
| Local named (default) | `false` | empty | empty | empty |
| Bind | `false` | `none` | `bind` | `/appdata/siyuan` |
| NFS | `false` | `nfs` | `addr=host,rw,nfsvers=4` | `:/exports/siyuan` |
| External | `true` | — | — | — |

```env
# Local named
SIYUAN_DATA_VOLUME_TYPE=
SIYUAN_DATA_VOLUME_OPTS=
SIYUAN_DATA_VOLUME_PATH=

# Bind
SIYUAN_DATA_VOLUME_TYPE=none
SIYUAN_DATA_VOLUME_OPTS=bind
SIYUAN_DATA_VOLUME_PATH=/appdata/siyuan
```

```sh
docker volume create siyuan_workspace
```

## Required env

- `SIYUAN_DOMAIN`, `SIYUAN_APP_URL`
- `SIYUAN_ACCESS_AUTH_CODE` (auto-generated if placeholder)
