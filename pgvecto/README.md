# pgvecto

[pgvecto.rs](https://hub.docker.com/r/tensorchord/pgvecto-rs) (`tensorchord/pgvecto-rs:pg14-v0.2.0`) — PostgreSQL 14 with the `vectors` extension — on **TCP 5432**. Joins `dokploy-network`. **Not an HTTP app**: no Traefik/Homepage labels (`compose.yml` is a symlink of `docker-compose.yml`).

Port **5432 is not published on the host**. Other stacks on the overlay reach it as **`dokploy-pgvecto:5432`** (network alias) or `pgvecto:5432` (Compose service name).

Tunables match Immich-style pgvecto-rs: `shared_preload_libraries=vectors.so`, `search_path` includes `vectors`, `shared_buffers=512MB`, `max_wal_size=2GB`, `wal_compression=on`, `POSTGRES_INITDB_ARGS=--data-checksums`.

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${PGVECTO_ENV_FILE:-.env.example}`; production: `PGVECTO_ENV_FILE=.env`. `environment:` wins on key conflicts.

```sh
make pgvecto-setup
make pgvecto-stack-up
# or
make pgvecto-compose-up
```

## Base path

**Not applicable.** PostgreSQL is TCP, not HTTP. `PGVECTO_BASE_PATH=/` is unused.

## Auth and persistence

`make pgvecto-setup` generates `PGVECTO_PASSWORD` (openssl hex) when empty, and sets `DEFAULT_NETWORK_EXTERNAL` (`true` iff `DEFAULT_NETWORK_NAME` is `dokploy-network` or empty).

Default database/user: `PGVECTO_DATABASE=pgvecto`, `PGVECTO_USER=pgvecto` (maps to `POSTGRES_*`). Data in `/var/lib/postgresql/data` via `PGVECTO_DATA_BIND` (named volume by default — do not put `/appdata/...` in that var for Swarm).

Clients on the overlay:

```
postgresql://${PGVECTO_USER}:${PGVECTO_PASSWORD}@dokploy-pgvecto:5432/${PGVECTO_DATABASE}
```

Override the alias with `PGVECTO_NETWORK_ALIAS` (default `dokploy-pgvecto`). Swarm updates use `stop-first` (single replica + datadir).

## Required env

| Variable | Notes |
|----------|--------|
| `PGVECTO_PASSWORD` | Generated by `make pgvecto-setup` if empty (`POSTGRES_PASSWORD`) |
| `PGVECTO_DATABASE` / `PGVECTO_USER` | Default `pgvecto` / `pgvecto` |
| `PGVECTO_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `PGVECTO_NETWORK_ALIAS` | Overlay DNS alias (default `dokploy-pgvecto`) |
| `PGVECTO_DATA_BIND` | Named volume name (default `pgvecto-data`) |
| `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL` | Default join `dokploy-network` with `external=true` |

Do not commit `pgvecto/.env` or real passwords.
