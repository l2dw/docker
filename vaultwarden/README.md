# Vaultwarden

[Vaultwarden](https://github.com/dani-garcia/vaultwarden) (`vaultwarden/server`) — unofficial Bitwarden-compatible server. Joins `dokploy-network`; does not run Traefik/WAF. HTTP **80** inside the container (Traefik); data at `/data`. Default DB is **SQLite** (`DATABASE_URL=sqlite:///data/db.sqlite3`).

Docs: [Docker wiki](https://github.com/dani-garcia/vaultwarden/wiki), [alternate base dir](https://github.com/dani-garcia/vaultwarden/wiki/Using-an-alternate-base-dir), [proxy examples](https://github.com/dani-garcia/vaultwarden/wiki/Proxy-examples), [admin page](https://github.com/dani-garcia/vaultwarden/wiki/Enabling-admin-page).

`.env` is **not** read by `docker stack deploy` alone — use Make (root `.env` is exported). Compose `env_file` loads `${VAULTWARDEN_ENV_FILE:-.env.example}`; production: `VAULTWARDEN_ENV_FILE=.env`. `environment:` wins on key conflicts.

```sh
make vaultwarden-setup \
  VAULTWARDEN_DOMAIN=example.com \
  VAULTWARDEN_APP_URL=https://example.com/vaultwarden \
  VAULTWARDEN_BASE_PATH=/vaultwarden
make vaultwarden-stack-up
# or
make vaultwarden-compose-up
```

On the `vaultwarden` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `vaultwarden/`.

| File | Labels |
|------|--------|
| [`compose.yml`](compose.yml) | None (no Traefik / Homepage) |
| [`docker-compose.yml`](docker-compose.yml) | Traefik + Homepage — used by `make` |

Web vault needs **HTTPS** in browsers (Web Crypto). Enable Traefik TLS (`VAULTWARDEN_TLS_ENABLED=true`, `VAULTWARDEN_ENTRYPOINTS=websecure`) or terminate TLS in front. Websocket notifications use the same HTTP port (no extra 3012 publish).

## Base path

**Supported** via vendor **`DOMAIN`** (`VAULTWARDEN_APP_URL`) — include the path, no trailing slash. Do **not** use Traefik `stripPrefix`: Vaultwarden mounts API routes under that path.

- Default: `VAULTWARDEN_BASE_PATH=/vaultwarden` and `VAULTWARDEN_APP_URL=http://example.com/vaultwarden`
- Dedicated subdomain: `VAULTWARDEN_BASE_PATH=/` and `VAULTWARDEN_APP_URL=https://vault.example.com`

Admin UI: `${VAULTWARDEN_APP_URL}/admin`. Web vault: `${VAULTWARDEN_APP_URL}/` (trailing slash in the browser is OK).

## Database

Vendor **`DATABASE_URL`** (`VAULTWARDEN_DATABASE_URL`). Default SQLite file in the data volume. No Postgres service in this stack — point at an existing DB if needed:

```
VAULTWARDEN_DATABASE_URL=postgresql://vaultwarden:ChangeMe@postgres:5432/vaultwarden
```

## Signups and admin

`VAULTWARDEN_SIGNUPS_ALLOWED=false` by default. Invite users from `/admin` (`INVITATIONS_ALLOWED=true`) or temporarily set signups to `true` for the first account.

`make vaultwarden-setup` generates `VAULTWARDEN_ADMIN_TOKEN` (`openssl rand -hex 32`) if empty. Prefer hashing later (`docker exec … /vaultwarden hash`) and storing the argon2 PHC in `.env` (quote `$` for Make).

## Required env

| Variable | Notes |
|----------|--------|
| `VAULTWARDEN_APP_URL` | Public URL including base path (vendor `DOMAIN`) |
| `VAULTWARDEN_DOMAIN` | Traefik `Host()` |
| `VAULTWARDEN_BASE_PATH` | Traefik `PathPrefix` (default `/vaultwarden`) |
| `VAULTWARDEN_ADMIN_TOKEN` | Admin panel (`/admin`); generated by setup |
| `VAULTWARDEN_DATABASE_URL` | Vendor `DATABASE_URL` (default SQLite `sqlite:///data/db.sqlite3`; Postgres `postgresql://user:ChangeMe@host:5432/db`) |
| `VAULTWARDEN_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `VAULTWARDEN_SIGNUPS_ALLOWED` | Default `false` |
| SMTP `VAULTWARDEN_SMTP_*` | Optional; needed for invitations/email 2FA |

`env_file` applies to **Compose**. For Swarm `stack deploy`, rely on Make-exported root `.env` + `environment:` interpolation (`env_file` is not applied the same way).

## Volumes

| Mount | Default | Role |
|-------|---------|------|
| `/data` | `vaultwarden-data` | SQLite file (default), attachments, `config.json` |
