# mariadb

Official [MariaDB](https://hub.docker.com/_/mariadb) (`docker.io/library/mariadb:11`) on **TCP 3306**. Uses the stack-local `mariadb-network` by default (`external=false`). **Not an HTTP app**: no Traefik/Homepage labels (`compose.yml` is a symlink of `docker-compose.yml`).

On the overlay, reach MariaDB as **`mariadb-server:3306`** (network alias) or `server:3306` (Compose service name). Host publish defaults to **`23306→3306`** (`MARIADB_PUBLISHED_PORT` / `MARIADB_PORT`, Swarm `ingress`, protocol `tcp`). Prefer overlay access; for intentional inter-stack access, use a shared external network.

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${MARIADB_ENV_FILE:-.env.example}`; production: `MARIADB_ENV_FILE=.env`. `environment:` wins on key conflicts.

```sh
make mariadb-setup
make mariadb-stack-up
# or
make mariadb-compose-up
```

On the `mariadb` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `mariadb/`.

## Base path

**Not applicable.** MariaDB is TCP, not HTTP. `MARIADB_BASE_PATH=/` is unused.

## Auth and persistence

`make mariadb-setup` generates `MARIADB_ROOT_PASSWORD` and `MARIADB_PASSWORD` (openssl hex) when empty, and enforces the stack-local defaults `DEFAULT_NETWORK_NAME=mariadb-network` and `DEFAULT_NETWORK_EXTERNAL=false`.

Default database/user: `MARIADB_DATABASE=mariadb`, `MARIADB_USER=mariadb`. Data is mounted at `/var/lib/mysql` from `MARIADB_DATA_HOST_PATH` (default `mariadb-data`), with configurable volume driver options.

Clients on the overlay:

```
mysql://${MARIADB_USER}:***@mariadb-server:3306/${MARIADB_DATABASE}
```

Root:

```
mysql://root:${MARIADB_ROOT_PASSWORD}@mariadb-server:3306/
```

Healthcheck uses the image `healthcheck.sh --connect --innodb_initialized`. Override the alias with `MARIADB_NETWORK_ALIAS` (default `mariadb-server`). Swarm updates use `stop-first` (single replica + datadir).

## Required env

| Variable | Notes |
|----------|--------|
| `MARIADB_ROOT_PASSWORD` | Generated by `make mariadb-setup` if empty |
| `MARIADB_PASSWORD` | Generated by `make mariadb-setup` if empty |
| `MARIADB_DATABASE` / `MARIADB_USER` | Default `mariadb` / `mariadb` |
| `MARIADB_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `MARIADB_NETWORK_ALIAS` | Stack-local DNS alias (default `mariadb-server`) |
| `MARIADB_PUBLISHED_PORT` / `MARIADB_PORT` | Host→container publish (default `23306`→`3306`) |
| `MARIADB_PORT_MODE` | Swarm publish mode (`ingress`\|`host`; protocol is `tcp` in compose) |
| `MARIADB_HEALTHCHECK_*` | Interval/timeout/retries/start_period for `healthcheck.sh` |
| `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL` | Default stack-local `mariadb-network` with `external=false`; set both explicitly for shared external access |
| `MARIADB_DATA_HOST_PATH` / `MARIADB_DATA_CONTAINER_PATH` | Volume source (`mariadb-data`) and container mount (`/var/lib/mysql`) |
| `MARIADB_DATA_VOLUME_DRIVER*` | Optional Docker volume driver and `driver_opts` overrides |

Do not commit `mariadb/.env` or real passwords.
