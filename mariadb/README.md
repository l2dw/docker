# mariadb

Official [MariaDB](https://hub.docker.com/_/mariadb) (`docker.io/library/mariadb:11`) on **TCP 3306**. Joins `dokploy-network`. **Not an HTTP app**: no Traefik/Homepage labels (`compose.yml` is a symlink of `docker-compose.yml`).

Port **3306 is not published on the host**. Other stacks on the overlay reach MariaDB as **`dokploy-mariadb:3306`** (network alias, Dokploy-style) or `mariadb:3306` (Compose service name).

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${MARIADB_ENV_FILE:-.env.example}`; production: `MARIADB_ENV_FILE=.env`. `environment:` wins on key conflicts.

```sh
make mariadb-setup
make mariadb-stack-up
# or
make mariadb-compose-up
```

On the `mariadb` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `mariadb/`.

## Base path

**Not applicable.** MariaDB is TCP, not HTTP. `MARIADB_BASE_PATH=/` is unused.

## Auth and persistence

`make mariadb-setup` generates `MARIADB_ROOT_PASSWORD` and `MARIADB_PASSWORD` (openssl hex) when empty, and sets `DEFAULT_NETWORK_EXTERNAL` (`true` iff `DEFAULT_NETWORK_NAME` is `dokploy-network` or empty).

Default database/user: `MARIADB_DATABASE=mariadb`, `MARIADB_USER=mariadb`. Data in `/var/lib/mysql` (`MARIADB_DATA_DIR` named volume by default).

Clients on the overlay:

```
mysql://${MARIADB_USER}:${MARIADB_PASSWORD}@dokploy-mariadb:3306/${MARIADB_DATABASE}
```

Root:

```
mysql://root:${MARIADB_ROOT_PASSWORD}@dokploy-mariadb:3306/
```

Override the alias with `MARIADB_NETWORK_ALIAS` (default `dokploy-mariadb`). Swarm updates use `stop-first` (single replica + datadir).

## Required env

| Variable | Notes |
|----------|--------|
| `MARIADB_ROOT_PASSWORD` | Generated by `make mariadb-setup` if empty |
| `MARIADB_PASSWORD` | Generated by `make mariadb-setup` if empty |
| `MARIADB_DATABASE` / `MARIADB_USER` | Default `mariadb` / `mariadb` |
| `MARIADB_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `MARIADB_NETWORK_ALIAS` | Overlay DNS alias (default `dokploy-mariadb`) |
| `DEFAULT_NETWORK_NAME` / `DEFAULT_NETWORK_EXTERNAL` | Default join `dokploy-network` with `external=true` |

Do not commit `mariadb/.env` or real passwords.
