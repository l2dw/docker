# hedgedoc

[HedgeDoc](https://hedgedoc.org) collaborative markdown (`quay.io/hedgedoc/hedgedoc`). **External Postgres** (`CMD_DB_URL`); no database or Redis in this stack (HedgeDoc 1.x has no Redis env). Joins `dokploy-network`. Traefik/Homepage labels live only in `docker-compose.yml`. Port **3000 is not published**.

`.env` is **not** read by `docker stack deploy` alone — use Make. Compose `env_file` loads `${HEDGEDOC_ENV_FILE:-.env.example}`; production: `HEDGEDOC_ENV_FILE=.env`. `environment:` wins on key conflicts.

Create the Postgres database and role first (e.g. on `dokploy-postgresql`), then:

```sh
make hedgedoc-setup \
  HEDGEDOC_DOMAIN=hedgedoc.example.com \
  HEDGEDOC_DB_URL='postgres://hedgedoc:secret@dokploy-postgresql:5432/hedgedoc'
make hedgedoc-stack-up
# or
make hedgedoc-compose-up
```

`hedgedoc-setup` generates `HEDGEDOC_SESSION_SECRET` when empty or `ChangeMe`. `CMD_DOMAIN` is hostname only (no `https://`).

On the `hedgedoc` branch, root `README.md` / `compose.yml` / `docker-compose.yml` are symlinks into `hedgedoc/`.

## Base path

Default **`HEDGEDOC_BASE_PATH=/`**: Traefik `Host` + `PathPrefix(/)` (the whole site at `http://hedgedoc.example.com/`). Keep `HEDGEDOC_URL_PATH` and `HEDGEDOC_MIDDLEWARES` **empty** — do **not** strip `/`.

Subpath (optional): `HEDGEDOC_BASE_PATH=/hedgedoc`, `HEDGEDOC_URL_PATH=hedgedoc` (`CMD_URL_PATH`, no slashes), `HEDGEDOC_MIDDLEWARES=stripprefix-hedgedoc`, `HEDGEDOC_HOMEPAGE_HREF=http://hedgedoc.example.com/hedgedoc`. The process still listens at `/`; Traefik strips the prefix.

HTTPS behind Traefik: `HEDGEDOC_PROTOCOL_USESSL=true` and `HEDGEDOC_URL_ADDPORT=false`.

## Required env

| Variable | Notes |
|----------|--------|
| `HEDGEDOC_DOMAIN` | Traefik Host() and `CMD_DOMAIN` (warns if `example.com`) |
| `HEDGEDOC_DB_URL` | External Postgres DSN (warns if `ChangeMe`) |
| `HEDGEDOC_SESSION_SECRET` | Generated by `hedgedoc-setup` |
| `HEDGEDOC_ENV_FILE` | Compose dotenv (default `.env.example`) |
| `APP_NAME` | Optional. Dokploy sets this; **not** in `.env.example`. Traefik names default to `hedgedoc`. |

Do not commit `hedgedoc/.env` or real secrets.
